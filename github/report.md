# 自建Z-BlogPHP网站黑盒渗透测试报告

## 一、测试概述
1. 测试目标：个人自建博客网站
2. 测试环境：黑盒测试，无提前获取源码、服务器权限、网站管理员账号密码
3. CMS版本：Z-BlogPHP 1.7.5
4. Web服务：Nginx
5. 测试范围：仅对外可访问Web业务，不直接登录服务器，不执行破坏性操作
6. 测试目的：模拟外部攻击者视角，发现网站存在的安全风险，输出加固建议

## 二、信息收集阶段
1. 端口探测：使用Nmap对目标公网IP进行端口扫描，识别对外开放端口。
             发现22,80端口开放，25 端口、110 端口服务识别存疑，无法获取版本信息
2. Web指纹识别：通过Wappalyzer工具、HTTP响应头识别Web服务与CMS版本为Z?BlogPHP 1.7.5。
3. 目录与后台探测：
    站点Nginx配置自定义404错误页面，HTTP状态码始终返回200，造成自动化目录扫描工具识别失效。
    通过人工枚举方式，发现网站后台登录地址：`/zb_system/login.php`。
4. 敏感路径初步枚举：尝试探测robots.txt、install.php、配置文件等常见敏感文件。

## 三、漏洞手工测试
### 3.1 XSS跨站脚本测试
1. 后台登录页面反射型XSS：输入`<script>alert(1)</script>` payload，页面做输入过滤，未触发反射XSS漏洞。
2. 文章评论模块存储型XSS：评论区提交脚本payload，CMS对特殊HTML字符做转义处理，标签作为纯文本展示，**不存在存储XSS漏洞**。

### 3.2 SQL注入测试
文章详情页参数 `?id=3`，构造单引号payload `?id=3'` 测试，页面无数据库报错，未出现SQL注入漏洞。

### 3.3 文件包含、目录遍历漏洞测试
依次使用payload测试本地文件包含、路径穿越：
- `/?file=../../etc/passwd`
- `/zb_system/../../etc/passwd`

服务器未返回服务器本地文件内容，业务页面正常渲染，**不存在目录遍历、本地文件包含漏洞**。

### 3.4 未授权/越权访问测试
未登录状态直接访问后台管理页面`/zb_system/admin.php`，服务器强制跳转至登录页面，不存在未授权访问漏洞。

### 3.5 HTTP安全响应头检测
查看HTTP响应头：
- 已存在 `X?XSS?Protection: 1; mode=block`
- 缺少 `X?Content?Type?Options: nosniff`

风险等级：**低危**
风险描述：缺少该安全头，浏览器可能发生MIME类型嗅探，放大部分前端攻击风险。

### 3.6 历史CVE漏洞核查
查询 Z?BlogPHP 1.7.5 公开CVE漏洞，该版本多数可利用漏洞均**需要管理员登录权限**才能够触发。
本次为黑盒测试，测试过程未拿到管理员账号凭据，无法登录后台，因此后台类CVE无法进行实际复现验证。

> 补充说明：若后续获取管理员权限，可进一步针对后台文件上传、模板编辑功能做安全测试。

## 四、敏感文件探测结果
- `/robots.txt`：【结果：返回首页】
- `/install.php`：【结果：返回首页】
- `/zb_config.php`：PHP配置文件，浏览器访问会被PHP解析，不会泄露源码与数据库账号密码。

## 五、风险汇总
|风险名称|风险等级|是否可利用|
| ---- | ---- | ---- |
|缺少X?Content?Type?Options安全响应头|低危|否|
|SQL注入、XSS、文件包含、目录遍历|无风险|不可利用|
|后台CVE历史漏洞|条件依赖|黑盒条件无法复现|

> 总结：在外网黑盒视角下，目标网站无高危、中危可利用漏洞，仅存在一项低危配置缺陷。

## 六、安全加固修复建议
1. Nginx站点配置中增加响应头 `X?Content?Type?Options: nosniff`，防御MIME嗅探攻击。
2. 确认服务器上已经删除`install.php`安装残留文件，避免安装页面带来风险。
3. 管理员账号设置高强度复杂密码，开启登录验证码防护暴力破解；持续跟进CMS版本更新。
4. 收紧云服务器防火墙策略，只开放业务必需端口，缩小整体攻击面。
5. 建议定期做信息收集审计，避免后台路径泄露，增加后台IP访问限制。

## 七、测试说明
本测试全部在自建靶场环境完成，仅用于网络安全学习实践，不对第三方真实业务系统进行测试。
