# 个人Web站点渗透测试项目
> 靶场环境：自建轻量云服务器搭建的博客站点，仅用于安全学习，所有测试均在授权范围内完成。

## 项目简介
对自建博客网站完成完整黑盒渗透测试，流程包含：信息收集、端口扫描、指纹识别、目录爆破、漏洞探测、漏洞验证、风险修复，输出完整渗透测试报告。

## 测试流程
1. 信息收集：域名、公网IP、DNS信息
2. 端口服务扫描：使用Nmap探测开放端口与运行服务
3. Web指纹识别：识别CMS、中间件版本、后端语言
4. 目录爆破：扫描敏感路径
5. 漏洞探测与验证
6. 风险汇总，给出修复建议

## 文件说明
- `渗透测试报告.md`：完整测试报告，包含风险等级、复现步骤、修复方案
- `screenshot/`：存放扫描、漏洞验证截图

## 环境说明
靶机为本人自建服务器，测试行为全部合法授权，无对外恶意测试。
